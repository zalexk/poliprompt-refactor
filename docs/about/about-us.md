# About

## Project

PoliPrompt is an open-source framework developed as part of research in computational political science. It grew from a simple few-shot classification script into a stateful agentic system capable of handling text and multimodal data with human-in-the-loop active learning.

The accompanying paper is:

> **PoliPrompt: A High-Performance Cost-Effective LLM-Based Text Classification Framework for Political Science**
> [https://arxiv.org/abs/2409.01466](https://arxiv.org/abs/2409.01466)
